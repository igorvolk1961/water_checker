# BPMN v1 — UC5: Получение утверждённых результатов испытаний (Ground Truth) из «БИТ:LIMS»
> **Канонический BPMN:** `bpmn/uc5.bpmn` (BPMN 2.0, bpmn.io / Camunda Modeler) · схема: `bpmn/uc5.svg`


**Версия:** 0.2 (C-04, I-6; переопределение UC5 — по редакции ведущего от 2026-10-12, `change_log.md`). FR-08, FR-09; LGL-01/02/07 в редакции ведущего.

> **Суть (UC5 в редакции ведущего).** Лабораторный контур (ввод результатов, формирование и утверждение протокола, выгрузка во ФГИС Росаккредитации) выполняется в «БИТ:LIMS» и является **Out-of-Scope** для AquaPredict. AquaPredict получает утверждённые результаты как целевую переменную (Ground Truth) для обучения и оценки.

## Дорожки

1. **«БИТ:LIMS» (1С)** — лабораторный контур (Out-of-Scope)
2. **Система AquaPredict**

## Границы (LGL, редакция ведущего)

- AquaPredict **не формирует, не подписывает и не выгружает** протоколы: формирование/подписание в AquaPredict запрещено (LGL-07), юридическая значимость — в контуре 1С (ПЭП руководителя лаборатории, LGL-02), выгрузка во ФГИС — штатный контур 1С (LGL-01).
- Доработки 1С для ФГИС/ЭП — вне проекта (`01_vision_and_scope.md`, Out-of-Scope «Лабораторный учёт и прослеживаемость»).

## Для бэклога (I-6; эпик EPIC-07 — «Получение утверждённых результатов испытаний (OData) для Ground Truth»)

Кандидаты в истории: периодическое чтение результатов и статусов; информационная сверка со справочником; сохранение Ground Truth с привязкой к партии/пробе; отображение статуса ФГИС/UUID (SCR-05).
