## Правило изменения

1. Предложение изменения (автор, причина) → PR.
2. Оценка влияния: FR (коллега), бэклог/стоимость (ведущий).
3. Ревью и одобрение ведущего; при влиянии на объём — согласование с заказчиком.
4. Запись в журнал; при необходимости — версионирование артефакта.
