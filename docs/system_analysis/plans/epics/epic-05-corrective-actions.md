# EPIC-05 — Управление корректирующими действиями

- **Релиз:** R1 · **Оценка:** 200 ч / 450 000 ₽
- **Источники:** US-05.1 · FR-06, FR-12 · SCR-02/03 · state ST-02/ST-04 · C4-3 (`ALERT`, `SYNC`)
- **Цель:** вести инцидент и связанную задачу на корректирующее действие (в 1С) с вердиктом.

## Задачи

- T-05.1 Создание инцидента из алерта ([Новый/Подтверждён/Ложный_алерт/Закрыт]).
- T-05.2 Создание задачи на корректирующее действие в 1С (HTTP) с рекомендованными шагами.
- T-05.3 Синхронизация статуса задачи; результат [Выполнено/Отменено].
- T-05.4 Вердикт инцидента — отдельная аудируемая запись (`ВердиктИнцидента`: значение, причина, дата, автор) — решение В-1.
- T-05.5 Возврат в [Новый] при результате [Отменено] (FR-06.6, В-2).
- T-05.6 Блокировка закрытия партии до [Закрыт] (FR-01.4).
- T-05.7 **API-компонент инцидентов/задач:** `/incidents`, `/incidents/{id}`, `/incidents/{id}/verdict`, `/tasks`.
- T-05.8 Тесты переходов состояний инцидента (state-модель).

## Зависимости

- EPIC-04. Опирается EPIC-13.

## Definition of Done

- Задача создаётся/закрывается в 1С; вердикт и результат разведены; причина вердикта фиксируется; блокировка партии работает.

## Риски

- Смешение сущностей «результат» vs «вердикт» (устранено доменной моделью).
