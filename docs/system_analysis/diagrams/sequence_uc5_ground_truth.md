# Sequence v1 — UC5 (редакция ведущего): получение Ground Truth из «БИТ.Лаборатории»

**Версия:** 0.2 (C-05/C-07). Заменяет sequence_uc5_protocol_export (старый UC5 с экспортом — Out-of-Scope по редакции ведущего от 2026-10-12). Показывает: лабораторный контур — в 1С, AquaPredict читает утверждённые результаты и замыкает их в обучающий контур. Термины — `02_glossary.md`; процесс — BPMN UC5 (`bpmn_uc5_ground_truth.md`).

```mermaid
sequenceDiagram
    autonumber
    participant ЛБ as Лаборант / РЛ (в 1С)
    participant 1С as БИТ.Лаборатория (1С)
    participant AP as AquaPredict
    participant МЛ as Контур обучения (MLOps)

    ЛБ->>1С: результаты анализа, формирование протокола
    1С->>1С: утверждение протокола (ПЭП руководителя лаборатории — контур 1С, LGL-02)
    1С->>1С: выгрузка во ФГИС — штатный функционал 1С (LGL-01, Out-of-Scope)
    AP->>1С: периодическое чтение утверждённых результатов по OData (FR-08.1, EPIC-07; ≤ 60 запросов/мин — NFR-6)
    AP->>AP: информационная сверка со справочником нормативов (подсветка SCR-04; решение — в 1С, LGL-11)
    AP->>AP: сохранение Ground Truth с привязкой к партии/пробе + чтение статуса ФГИС/UUID (FR-09.3, SCR-05 read-only)
    AP->>МЛ: связка «проба → срез телеметрии за окно (2 ч)» → метка (приоритет: протокол > вердикт, FR-11.1)
    alt источники согласованы
        МЛ->>МЛ: пример [Размеченный]
    else источники расходятся
        МЛ->>МЛ: карантин «Конфликт разметки» (FR-11.2, поток 6б)
    end
```

## Замечания

- AquaPredict не формирует, не подписывает и не выгружает протоколы (LGL-01/02/07 в редакции ведущего); доработки 1С — вне проекта.
- Старый sequence (экспорт/ЭП) удалён — заменён этим; это часть синхронизации C-07.
