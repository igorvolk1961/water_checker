- **Релиз:** R1–R2 · **Оценка:** 160 ч / 350 000 ₽
- **Источники:** US-13.1, US-13.2 · FR-05, FR-06, FR-12 · SCR-01…12 · UI-01…08 · ST-01…07 · C4-2 («Веб-консоль») · OQ-12
