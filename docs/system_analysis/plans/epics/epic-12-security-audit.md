# EPIC-12 — Безопасность, ПДн, аудит

- **Релиз:** R0–R1 (сквозной) · **Оценка:** 245 ч / 540 000 ₽
- **Источники:** US-12.1 · FR-14 · SCR-11 · NFR-8…11 · C4-3 (`RBAC`, `AUDIT`) · LGL-03/05/10/14
- **Цель:** обеспечить доступ, защиту ПДн, неизменяемый аудит и валидацию ПО.

## Задачи

- T-12.1 RBAC: 7 ролей (ГТ, ОЛ, ЛБ, РЛ, DS, АДМ, КИПиА) и матрица прав.
- T-12.2 Аутентификация консоли (AD/LDAP или локальные УЗ), сессии (NFR-8).
- T-12.3 Транспортная безопасность: HTTPS/TLS для OData/HTTP и MQTT (NFR-9).
- T-12.4 Маскирование ПДн; основания обработки (ФЗ-152) — LGL-05, §I.
- T-12.5 Неизменяемый аудит-лог: «рекомендация/решение/действие» + источник (AquaPredict/1С) — LGL-10.
- T-12.6 Выборочный контроль решений (automation bias) и экспорт аудита — LGL-14, FR-14.5.
- T-12.7 **API-компоненты:** `/auth/*`, `/audit`, `/audit/export`.
- T-12.8 Валидация ПО (ГОСТ ISO/IEC 17025-2019) и чек-лист соответствия (`legal/` §H).
- T-12.9 Резервное копирование; RTO ≤ 4 ч / RPO ≤ 15 мин (NFR-10).

## Зависимости

- Сквозной (старт в R0).

## Definition of Done

- RBAC/аутентификация/TLS/аудит/защита ПДн работают; чек-лист LGL закрыт; бэкапы и восстановление проверены.

## Риски

- Нарушения ФЗ-152 (PRJ-12); несоответствие форматов аудита ожиданиям проверяющих.
