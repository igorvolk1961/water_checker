# Sequence v1 — UC4: внеплановый отбор и формирование «золотого стандарта» данных

**Версия:** 0.1 (C-05). Показывает замыкание контура UC2 → UC4 → UC5 → UC6: алерт превращается в размеченный пример. Термины — `02_glossary.md`; процессы — BPMN UC4.

```mermaid
sequenceDiagram
    autonumber
    participant СК as Риск-скоринг / инцидент
    participant 1С as БИТ.Лаборатория (1С)
    participant ЛБ as Лаборант
    participant ЛАБ as Лабораторный анализ
    participant МЛ as Контур обучения (MLOps)

    СК->>1С: HTTP-сервис: задание «Внеплановый отбор пробы»,<br/>приоритет «Срочно» (FR-07.1)
    Note over СК,1С: NFR-6: ≤ 60 запросов/мин, очередь
    1С->>ЛБ: уведомление штатными средствами 1С (FR-07.2,<br/>канал — открытый вопрос 4)
    ЛБ->>ЛБ: физический отбор, стерильная тара, маркировка (вне систем, HITL)
    ЛБ->>1С: сканирование штрихкода — подтверждение отбора<br/>(Chain of Custody ведёт 1С, FR-07.3)
    1С-->>СК: статус задания и пробы (OData, FR-07.3)
    Note over СК: ссылка «инцидент → задание → проба» (FR-07.4)
    ЛАБ->>1С: результат анализа → протокол испытаний (ground truth)
    1С-->>МЛ: результаты LAB-01…16, статусы протоколов (OData, FR-08.1)
    МЛ->>МЛ: связка «проба → срез телеметрии за окно (2 ч)» (FR-08.4)
    alt протокол и вердикт согласованы
        МЛ->>МЛ: пример [Размеченный]: Feature Vector + метка<br/>(приоритет: протокол > вердикт, FR-11.1)
    else источники расходятся
        МЛ->>МЛ: карантин «Конфликт разметки» —<br/>в обучении не используется (поток 6б, FR-11.2)
    end
    МЛ-->>МЛ: уведомление DS «Накоплено N примеров» (SCR-07)
```

## Замечания

- AquaPredict не ведёт журнал проб — всё чтение из 1С (вариант A, FR-08.2).
- True Positive / False Positive фиксируются автоматически из связки «прогноз → факт» (UC6, раздел «золотой стандарт»).
- Диаграмма — источник требований к приёму OData-выгрузки и к справочнику приоритетов меток (FR-11.1).
