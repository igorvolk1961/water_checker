# EPIC-11 — Дашборд метрик модели

- **Релиз:** R2 · **Оценка:** 160 ч / 350 000 ₽
- **Источники:** US-11.1 · FR-13 · SCR-06/11 · `kpi.md` §2–§3 · LGL-09
- **Цель:** показать технологу/ML-инженеру метрики по слоям, рабочую точку и статус модели.

## Задачи

- T-11.1 Метрики по слоям: Recall/Precision/FPR/FNR/F1 + Baseline-метрика.
- T-11.2 Бюджет алертов и рабочая точка (порог, остаточные FPR/FNR, признак утверждения).
- T-11.3 Статус модели (Shadow/Advisor/Production) и история дрейфа.
- T-11.4 **API-компонент метрик:** `/metrics/model`, `/metrics/operating-point`.
- T-11.5 Администрирование порога (SCR-11, RBAC-админ).

## Зависимости

- EPIC-04 (базово), EPIC-09.

## Definition of Done

- Метрики по слоям и рабочая точка отображаются; порог утверждается и меняется только администратором.

## Риски

- Расхождение определений метрик с `kpi.md` (контролируется глоссарием §6).
