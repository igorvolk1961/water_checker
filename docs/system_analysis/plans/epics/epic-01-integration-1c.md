# EPIC-01 — Интеграция с «БИТ.Лаборатория»

- **Релиз:** R0 · **Оценка:** 300 ч / 650 000 ₽
- **Источники:** US-01.1 · FR-01, FR-15 · SCR-01 · C4-2 (контейнер «Сервис синхронизации с 1С»), C4-3 (`SYNC`) · `requirements/integration_contract_1c.md`
- **Цель:** обеспечить обмен с 1С: чтение (OData) и запись (HTTP) с соблюдением ограничений.

## Задачи

- T-01.1 OData-клиент чтения: партии, пробы, результаты LAB-01…16, статусы протоколов/ФГИС.
- T-01.2 HTTP-писатель: задачи (корректирующее действие, внеплановый отбор), вердикты, статусы блокировки партии.
- T-01.3 Очередь/rate-limit ≤ 60 req/min (Redis, AOF), ретраи с экспоненциальной задержкой.
- T-01.4 Ключ идемпотентности для всех операций записи (FR-15.6).
- T-01.5 Маппинг сущностей 1С↔AquaPredict; версионирование контракта (LGL-R3).
- T-01.6 **API-компонент синхронизации:** эндпоинты `/sync/parties`, `/sync/lab-results`, `/sync/status`, `/sync/queue` (мониторинг очереди для SCR-11).
- T-01.7 **Имитатор «мок-1С»** (тестовый стенд): OData-эндпоинты + HTTP-сервис, отдача тестовых партий/проб/результатов и приём задач — для интеграционных тестов без прода 1С.
- T-01.8 Контрактные и интеграционные тесты на моке 1С.

## Зависимости

- Нет (стартовый эпик); на него опираются EPIC-02, EPIC-07.

## Definition of Done

- Чтение/запись работают на моке и на тестовом контуре 1С; лимит ≤ 60 req/min соблюдается; идемпотентность подтверждена тестами; контракт версионируется.

## Риски

- «Зоопарк» сущностей 1С (PRJ-01); настройка endpoints — зона администратора 1С (FR-15.4).
