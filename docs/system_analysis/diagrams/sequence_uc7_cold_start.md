# Sequence v1 — UC7: первичная калибровка (Cold Start)

**Версия:** 0.1 (C-05, дополнение). Показывает конвейер от импорта архива до переключения в Advisor, включая поток 7а (недостаток данных). Термины — `02_glossary.md`; процесс — BPMN UC7 (`bpmn_uc7_cold_start.md`); состояния — ST-06/ST-05.

```mermaid
sequenceDiagram
    autonumber
    participant DS as ML-инженер (Data Scientist)
    participant ETL as Система (ETL-пайплайн)
    participant АРХ as Архивы (SCADA Historian,<br/>лабораторные журналы)
    participant ГТ as Главный технолог

    DS->>ETL: запуск мастера Cold Start (SCR-08)
    ETL->>АРХ: импорт логов SCADA (CSV / OPC-UA HDA)<br/>+ лабораторных журналов (FR-10.1)
    ETL->>DS: отчёт о качестве импорта (объём, ошибки форматов)

    alt архивных данных достаточно
        ETL->>АРХ: матчинг «срез телеметрии за окно (2 ч) → проба» (FR-10.2)
        ETL->>DS: отчёт о матчинге (доля ≥ 90 % — kpi §4,<br/>список несопоставленных с причинами)
        opt повторный матчинг на подмножестве
            DS->>ETL: перезапуск матчинга
        end
    else данных недостаточно (поток 7а)
        ETL->>ETL: Pre-training на синтетике цифрового двойника —<br/>продление периода калибровки (явный шаг мастера)
    end

    ETL->>ETL: обучение Baseline-профиля (Anomaly Detection,<br/>без размеченных примеров брака, FR-10.3)
    ETL->>DS: профиль [Черновик] (ST-06)
    DS->>ETL: размещение в Shadow Mode (ST-05)
    ETL->>ETL: Shadow: прогнозы персоналу не показываются,<br/>накапливаются метрики точности (FR-04.2)

    ГТ->>ETL: подтверждение профиля как «Эталонный»<br/>(фиксация в аудите, UI-07)

    loop до выполнения критериев перехода
        ETL->>ETL: накопление метрик
    end
    alt критерии §4 выполнены<br/>(Recall ≥ 0,75 при FPR ≤ 0,10,<br/>≥ 4 нед стабильности, ≥ N инцидентов)
        ETL->>DS: готовность к переключению
        DS->>ETL: перевод в Advisor (решение фиксируется, FR-04.3)
    else критерии не выполнены
        ETL->>ETL: продолжение Shadow (возврат к накоплению)
    end
```

## Замечания

- Baseline-профиль и Shadow Mode — вход для FR-03/FR-04 (Слой 1 стартует сразу, Слой 2 — по критериям; «Фаза движка» vs «Фаза внедрения» — В-4).
- Матчинг архива использует тот же механизм, что и связка в текущей работе (FR-08.4, UC4).
