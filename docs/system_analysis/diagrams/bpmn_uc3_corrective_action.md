# BPMN v1 — UC3: Регистрация и контроль выполнения корректирующего действия

**Версия:** 0.1 (C-04, I-6). **Независимо от вилки A/B.**
Система не выполняет действие сама — она управляет бизнес-процессом и документооборотом (In-Scope, `04_use_cases.md`). FR-06, LGL-10.

## Дорожки

1. **Система AquaPredict**
2. **«БИТ:LIMS» (1С)**
3. **Персонал** (главный технолог / оператор линии)

## Границы

- Результат корректирующего действия [Выполнено / Отменено] ≠ вердикт по инциденту [Подтверждён / Ложное срабатывание] — разные сущности (FR-06).
- Аудит различает: рекомендация системы / решение человека / фактическое действие (LGL-10).

## Для бэклога (I-6)

Кандидаты в истории: назначение и уведомление по задаче 1С; синхронизация статусов; фиксация результата и приложений; модель вердикта + причины; снятие блокировки партии.
