**Версия:** 0.1 (C-04, точка состыковки I-6). **Независимо от вилки A/B.**
Основной дифференциатор системы. Шаги соответствуют потоку UC2 (`04_use_cases.md`), сущности — FR-05/FR-06/FR-12, термины — `02_glossary.md`.

1. **Система AquaPredict** (ML-модуль, движок риск-скоринга)
2. **«БИТ:LIMS» (1С)** — точка интеграции

## Границы (LGL)

- Система **рекомендует**; решение и физическое действие — за персоналом (LGL-04, HITL).
- ML-алерт — не основание для браковки партии; решение — по лабораторному контролю (LGL-11).
- Управляющих команд в ПЛК/SCADA нет (NFR-7); запись — только задачи/статусы в 1С.

## Для бэклога (передача ведущему, I-6)

Кандидаты в истории: приём/связка телеметрии; расчёт скора и порог; budget-контроль алертов; создание инцидента + уведомления; карточка инцидента (SCR-02); вердикт и обратная связь; автосоздание задачи на корректирующее действие в 1С.
