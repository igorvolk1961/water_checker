# EPIC-09 — Движок риск-скоринга, Слой 2 (ML)

- **Релиз:** R2 · **Оценка:** 360 ч / 800 000 ₽
- **Источники:** US-09.1 · FR-04 · C4-3 (`ENGINE`, `TRAIN`) · `kpi.md` §2
- **Цель:** прогнозировать риск целевых показателей ML-моделью с горизонтом ≥ 2 ч.

## Задачи

- T-09.1 Обучение/инференс ML-модели (горизонт ≥ 2 ч) на оконных признаках (см. `docs/references/ml_anomaly_detection.md`).
- T-09.2 Сравнение со Слоем 1 и Baseline-метрикой.
- T-09.3 Критерии перехода Shadow→Advisor (Recall ≥ 0,75 при FPR ≤ 0,10; ≥ 4 недель; ≥ N инцидентов) — фиксация в журнале версий.
- T-09.4 Фиксация версии модели и откат при деградации (FR-04.5).
- T-09.5 **API-компонент инференса:** `/score/ml`, `/models/active`.
- T-09.6 Признаковый конвейер (оконные признаки, лаги) — общий с EPIC-10 (Feature Store).

## Зависимости

- EPIC-08. Опираются EPIC-10, EPIC-11.

## Definition of Done

- ML-прогноз выдаётся, работает в Shadow до выполнения критериев; версии фиксируются и откатываются.

## Риски

- Недостижение целевого Recall; дрейф модели.
