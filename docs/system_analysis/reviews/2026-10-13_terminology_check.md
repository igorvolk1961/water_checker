## 3. Новые находки для ведущего (дополнение к В-4/В-6)

1. **«Риск-скор» (глоссарий) vs «уровень_риска» (поле доменной модели)** — два имени одной величины. Предложение: поле доменной модели переименовать в `риск-скор` (или зафиксировать синонимию в глоссарии). В моих артефактах везде «риск-скор», поле доменной модели не трогаю.
2. **«Приёмник телеметрии»** — у меня компонент (FR-02.2, sequence UC2→UC3), в глоссарии есть только «IoT-шлюз». Предложение: добавить термин в глоссарий (приёмник — сервис AquaPredict, шлюз — оборудование линии) или переименовать мой компонент.
3. **«Обучающий_Пример» (доменная модель) vs «Размеченный пример (Labeled Data)» (UC6)** — у меня смешение («обучающий пример» / «Размеченный пример»); предложить синонимиию или один термин.
4. **«Заявка» (UC4, US-06.1 ведущего) vs «задание» (у меня: FR-07.1, SCR-03, диаграммы)** — два слова для одного артефакта отбора; у меня консистентно «задание», у ведущего смешано. Предложить «задание» (согласуется с «задача КА» в доменной модели).
