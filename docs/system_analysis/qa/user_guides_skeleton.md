# Руководства пользователя и администратора — каркасы

**Версия:** 0.1-каркас (2026-10-13). **Автор:** коллега. **Назначение:** обязательные документы поставки (ТЗ §5.7). Наполнение — по мере готовности экранов (R1 → руководство пользователя, R2/R3 → администратора). Термины — `02_glossary.md`; источники — `ui_requirements.md` v0.3, FR v1.1.

## Часть I. Руководство пользователя (web-консоль AquaPredict)

### 1. Введение
- Назначение системы; принцип «система рекомендует — решает человек» (HITL, LGL-04).
- Для кого: главный технолог, инженер КИПиА, руководитель лаборатории, ML-инженер (краткие роли — RBAC-матрица).

### 2. Начало работы
- Вход в систему (механизм — после В-7.2); восстановление доступа.
- Главное окно: шапка, индикатор синхронизации с 1С (что означает «норма / очередь / ошибка» — UI-08).

### 3. Работа с предупреждениями (ГТ)
- Читать ленту алертов: критичность, риск-скор, горизонт, источник (Слой 1/2).
- Подтвердить ознакомление с критическим алертом (зачем это нужно — NFR-4).
- Открыть карточку инцидента: тренды, рекомендация, порог рабочей точки.
- Зафиксировать вердикт [Подтверждён / Ложное срабатывание] с причиной — и почему вердикт ≠ результат корректирующего действия.
- Что происходит после вердикта: задача в 1С, снятие блокировки партии (FR-01.4).

### 4. Задачи: корректирующее действие и внеплановый отбор (ГТ/ОЛ/ЛБ)
- Где смотреть статусы задач (SCR-03); почему действия выполняются в 1С.
- Лаборанту: как приходит задание на внеплановый отбор и что с ним делать (канал 1С — OQ-04).

### 5. Аналитика по партии (ГТ/РЛ)
- Телеметрия + результаты анализов на одной оси; информационная сверка с нормативами.
- Экспорт среза для ML-инженера.

### 6. Мониторинг канала телеметрии (КИПиА)
- Статусы датчиков и их значения; буфер шлюза при потере связи.
- Действия при аномалии потока; подтверждение восстановления (UC8).

### 7. Метрики модели (DS/ГТ/РЛ)
- Как читать Recall/Precision/FPR/F1 по Слоям; что такое рабочая точка и кто её утверждает (LGL-09).

### 8. Частые вопросы и ограничения
- «Почему я не могу ввести результат анализа?» — журнал проб только в 1С (вариант A).
- «Почему алерт не бракует партию?» — LGL-11.
- Куда смотрит аудит-лог и что в него попадает.

## Часть II. Руководство администратора

### 1. Роли и доступ (RBAC)
- Матрица «роль × экран»; заведение пользователей; принцип минимальных прав.

### 2. Рабочая точка
- Изменение порога критического алерта: порядок, обязательное утверждение эксплуатантом, история изменений (LGL-09).

### 3. Справочник нормативов
- Актуализация СанПиН 1.2.3685-21 / ГОСТ 32220-2013: версии, даты, комментарий.

### 4. Интеграция с «1С»
- Endpoints OData/HTTP, лимит ≤ 60 запросов/мин, очередь и её мониторинг; действия при деградации (ST-07).

### 5. Персональные данные
- Маскирование, состав хранимых ПДн, сроки хранения (1 год — LGL-06), выгрузка аудита.

### 6. Резервное копирование и восстановление
- ⚠️ Наполняется после решения В-7.2 (RTO/RPO не определены).

### 7. Диагностика
- Где смотреть статус синхронизации, очередь, состояние датчиков; типовые ошибки и действия.
