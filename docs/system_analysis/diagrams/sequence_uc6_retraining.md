# Sequence v1 — UC6: переобучение модели и обработка дрейфа

**Версия:** 0.1 (C-05, дополнение). Показывает жизненный цикл версии модели от накопления примеров до развёртывания/отката. Термины — `02_glossary.md`; процесс — BPMN UC6 (`bpmn_uc6_retraining.md`); состояния — ST-05 (`state_model_and_batch.md`).

```mermaid
sequenceDiagram
    autonumber
    participant СИС as Система (фоновая агрегация)
    participant МЛ as Контур обучения (MLOps)
    participant DS as ML-инженер (Data Scientist)
    participant ГТ as Главный технолог

    loop непрерывно (UC2 → UC4 → UC5)
        СИС->>МЛ: связка «проба → срез телеметрии за окно (2 ч)»\n→ Feature Vector + метка (FR-08.4)
        Note over МЛ: приоритет метки: лабораторный протокол >\nвердикт технолога (прокси-метка, FR-11.1)
        alt источники согласованы
            МЛ->>МЛ: пример [Размеченный] в датасет
        else источники расходятся
            МЛ->>МЛ: карантин «Конфликт разметки» —\nв обучении не используется (поток 6б, FR-11.2)
            МЛ->>DS: уведомление о конфликте (SCR-07)
            DS->>МЛ: разрешение: выбор приоритетного источника\n(фиксация в аудите, UI-07)
        end
    end

    МЛ->>DS: «Накоплено N новых размеченных примеров» (SCR-07.2)
    DS->>МЛ: инициация переобучения (Retraining) на расширенном датасете
    МЛ->>МЛ: пайплайн обучения; метрики новой версии\n(Recall/Precision/FPR/F1 — пофазные цели, kpi §2)
    МЛ->>МЛ: сравнение с рабочей версией
    alt метрики в допустимом коридоре
        МЛ->>DS: таблица сравнения (SCR-07.3)
        DS->>МЛ: «Утвердить и развернуть» (HITL)
        МЛ->>МЛ: новая версия → Production (или Active — В-4),\nстарая → Архив; журнал версий (FR-11.4)
    else деградация метрик (Data Drift, поток 6а)
        МЛ-->>МЛ: отмена развёртывания
        МЛ->>МЛ: датасет — флаг «Требуется проверка аномалий»
        МЛ->>DS: уведомление (LGL-13)
        МЛ->>ГТ: уведомление — совместное расследование\nпричин изменения процесса
        Note over МЛ: рабочая версия продолжает обслуживать скоринг\n(откат ST-05, FR-04.5)
    end
```

## Замечания

- Мониторинг дрейфа выполняется непрерывно, не только при переобучении (FR-11.6, LGL-13) — отражается на SCR-06.
- Все решения DS (утверждение, разрешение конфликтов) фиксируются в аудите (LGL-10).
