AquaPredict — предиктивная аналитика качества бутилированной воды

Аналитическая надстройка над «БИТ:LIMS» (1С). Предсказываем риск брака заранее и подсказываем действие.

HITL — решение за человекомБез вмешательства в оборудование2026

Авторы: Баева Анастасия Сергеевна · Волков Игорь Анатольевич

Проблема

Контроль качества реактивен

  • Отклонения выявляются постфактум — партия уже произведена.
  • Телеметрия линии не используется для упреждающего контроля.
  • Итог — прямые потери (утилизация) и репутационные риски.
  • Цифры проблемы — допущение: партия ~6000 л, брак 3–5 %, ~300 тыс ₽/мес.

Решение и идея

Цифровой ассистент технолога

  • За 2 часа до, а не после выпуска партии.
  • Принцип HITL: система рекомендует, решение принимает человек.
  • Ранний сигнал → корректирующее действие → партия не становится браком.
  • Данные есть — добавляем предсказание и рекомендацию.

Границы проекта

Надстройка, а не самостоятельная LIMS

In-Scope

Телеметрия (OPC-UA/MQTT), риск-скоринг (Слой 1/2), алерты, инциденты и корректирующие действия, внеплановый отбор, Cold Start, MLOps, веб-консоль, интеграция с 1С.

Out-of-Scope

Лабораторный учёт и ФГИС (в «БИТ:LIMS»); прямое управление оборудованием (ПЛК/SCADA); ERP.

  • Обоснование: безопасность/ответственность, сложность сертификации, отсутствие двойного ввода.

Домен и состояния

    
Разведены результат и вердикт

    
    
      
  • Партия, показание датчика, алерт, инцидент, корректирующее действие, вердикт, проба, протокол, модель, обучающий пример.
    • 
      
  • Результат корректирующего действия [Выполнено/Отменено] ≠ вердикт инцидента [Подтверждён/Ложное срабатывание].
    • 
      
  • Состояния инцидента: Новый → Подтверждён / Ложный_алерт → Закрыт; возврат при отмене.

Модульный монолит + воркеры

Интеграция с 1С

    
Контракт и «мост»

    
    
      
  • Чтение — OData, запись — HTTP; ≤ 60 зап./мин; идемпотентность; очередь.
    • 
      
  • Доступ к реальному API заказчика не предоставлен; публичной техдокументации нет → имена условные.
    • 
      
  • При появлении доступа реализуется мост (adapter/ACL), маппящий реальные сущности на наши модели.

Экономика

    
Оценка честная

    
    
      
  • CAPEX: ПО ≈ 7,09 + оборудование ≈ 2,28 → ≈ 9,37 млн ₽; с резервом ≈ 11,2 млн ₽.
    • 
      
  • OPEX ≈ 1,2–2,4 млн ₽/год; экономия 0,4–2,4 млн ₽/год → окупаемость длинная.
    • 
      
  • Ценность дополняется снижением репутационных/нормативных рисков; принят фазовый MVP.
    •
