# Sequence v1 — UC2 → UC3: от показания датчика до закрытия корректирующего действия

**Версия:** 0.1 (C-05). Основной демонстрационный поток; показывает границы системы, интеграцию с 1С и точки применения NFR/LGL. Термины — `02_glossary.md`; процессы — BPMN UC2/UC3.

```mermaid
sequenceDiagram
    autonumber
    participant ДТ as Датчик (линия)
    participant ШЛ as IoT-шлюз
    participant ПР as Приёмник телеметрии
    participant СК as Риск-скоринг (Слой 1/2)
    participant АЛ as Контур алертинга
    participant 1С as БИТ:LIMS (1С)
    participant ГТ as Главный технолог
    participant ПРС as Персонал (ОЛ/ГТ)

    ДТ->>ШЛ: показание TEL-xx (≥ 1/мин)
    ШЛ->>ПР: телеметрия (OPC-UA / MQTT)
    Note over ШЛ,ПР: NFR-3, при потере связи — буфер ≤ 2 ч (NFR-2)
    ПР->>СК: ряд, привязанный к партии (FR-01.2)
    СК->>СК: расчёт риска

    alt риск ≥ рабочей точки (LGL-09, конфигурируемый порог)
        СК->>АЛ: RiskAlert (партия, TEL-код, риск-скор, горизонт, рекомендация)
        Note over СК,АЛ: NFR-1: latency ≤ 5 с от датчика
        АЛ->>АЛ: бюджет алертов ≤ 10/час (NFR-5): приоритизация, подавление дублей
        АЛ->>ГТ: push/SMS + алерт на SCR-01 (критический: красный, звук, подтверждение — NFR-4)
        ГТ->>АЛ: подтверждение ознакомления (→ аудит, LGL-10)
        АЛ->>СК: создание записи «Предиктивный инцидент» [Новый]
        СК->>1С: HTTP-сервис: задача «корректирующее действие» с рекомендованными шагами (FR-06.3)
        Note over СК,1С: NFR-6: ≤ 60 запросов/мин, пакетирование, очередь
        1С->>ПРС: назначение + уведомление штатными средствами 1С
        ПРС->>ПРС: физическое выполнение действия (вне систем, HITL — LGL-04)
        ПРС->>1С: закрытие задачи с приложением (фото/комментарий)
        1С-->>СК: статус задачи [Выполнено/Отменено] (чтение OData, LGL-10)
        alt [Выполнено]
            ГТ->>СК: вердикт [Подтверждён] (SCR-02) → инцидент [Закрыт]
        else [Отменено]
            СК->>ГТ: возврат инцидента на пересмотр (FR-06.6)
        end
        СК-->>1С: блокировка закрытия партии снята (FR-01.4)
    else риск < рабочей точки
        СК->>ПР: наблюдение продолжается
    end
```

## Границы и гарантии

- Управляющих команд в ПЛК/SCADA нет (NFR-7) — запись в 1С только задач/статусов.
- Вердикт ГТ — прокси-метка; основание решения о качестве — лабораторный контроль (LGL-11).
- Все шаги с участием человека фиксируются в аудите с различением «рекомендация системы / решение человека / фактическое действие» (LGL-10, FR-14.3).
- Параллельная ветка: при подтверждённом риске — задание внепланового отбора (sequence UC4).
