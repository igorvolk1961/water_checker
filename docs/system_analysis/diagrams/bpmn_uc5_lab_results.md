# BPMN v1 — UC5: Получение утверждённых результатов испытаний (вариант A)

**Версия:** 0.1 (C-04, I-6). **По варианту A (подтверждён 2026-10-12)** — заменяет standalone-логику исходного UC5.
Система **читает лабораторные результаты и статус выгрузки; формирование протоколов, ЭП и выгрузка во ФГИС — в контуре 1С/лаборатории** (FR-08, FR-09; устранение противоречия с ASM-09, п. G-1 ревью). LGL-01 (переформулирован ведущим), LGL-02, LGL-07, LGL-11.

## Дорожки

1. **Лаборант / Руководитель лаборатории (в 1С)**
2. **«БИТ.Лаборатория» (1С)** — контур валидации, ЭП и выгрузки
3. **Система AquaPredict**

## Границы (изменения против исходного UC5)

- AquaPredict **не формирует XML, не отправляет во ФГИС и не подписывает** — доработки 1С для этого вне проекта (`legal/…` §F, ASM-09).
- Шаги 4–5 исходного UC5 (авто-подписание системой, отправка) — переданы в контур 1С.
- AquaPredict отображает статусы и UUID; повторная отправка при отказе ФГИС — контур 1С.

## Для бэклога (I-6)

Кандидаты в истории: чтение протоколов/статусов; передача сопроводительных данных инцидента; отображение статуса ФГИС и UUID (SCR-05); связка ground truth → выборка.
