# EPIC-06 — Внеплановый (триггерный) отбор пробы

- **Релиз:** R1 · **Оценка:** 180 ч / 400 000 ₽
- **Источники:** US-06.1 · FR-07 · SCR-03/12 · BPMN uc4 · C4-3 (`ALERT`, `SYNC`)
- **Цель:** инициировать внеплановый отбор пробы по алерту и связать результат с телеметрией.

## Задачи

- T-06.1 Формирование задания «Внеплановый отбор» в 1С (приоритет «Срочно», партия, инцидент-источник).
- T-06.2 Уведомление лаборанту штатным каналом 1С (OQ-04).
- T-06.3 Чтение статуса задания/штрихкода (FR-07.3).
- T-06.4 Связка «инцидент → задание → проба → срез телеметрии (окно 2 ч)» для ground truth (FR-08.4).
- T-06.5 **API-компонент отбора:** `/sampling`, `/sampling/{id}`.
- T-06.6 Тесты связки с моком 1С (появление пробы → срез).

## Зависимости

- EPIC-04. Опираются EPIC-07, EPIC-08.

## Definition of Done

- Задание создаётся; событие отбора фиксируется; связка для обучения сохраняется.

## Риски

- Задержка статуса отбора в 1С (влияет на матчинг).
