# EPIC-14 — Мониторинг источников телеметрии (для инженера КИПиА)

- **Релиз:** R1 · **Оценка:** 140 ч / 300 000 ₽
- **Источники:** US-14.1 · FR-16 · SCR-09/12 · BPMN uc8 · C4-3 (`QUAL`) · NFR-2
- **Цель:** контролировать достоверность канала телеметрии и уведомлять КИПиА.

## Задачи

- T-14.1 Статусы датчиков TEL-01…13 ([Норма/Нет данных/Заморожено/Вне диапазона/Задержка]).
- T-14.2 Статус буфера шлюза и прогресс досинхронизации (NFR-2).
- T-14.3 Диагностические уведомления инженеру КИПиА.
- T-14.4 Пометка пониженной достоверности инцидентов/алертов по деградировавшему каналу.
- T-14.5 **API-компонент здоровья канала:** `/telemetry/health`, `/telemetry/sensors`, `/telemetry/buffer`.
- T-14.6 Тесты на имитаторе датчиков (сценарии деградации/восстановления).

## Зависимости

- EPIC-02.

## Definition of Done

- Деградация обнаруживается; КИПиА уведомляется; после восстановления источник возвращается в скоринг.

## Риски

- Ложные срабатывания диагностики (настраиваемые пороги).
