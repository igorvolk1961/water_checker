# AquaPredict LIMS — Журнал изменений базиса (Change Log)

Учёт изменений замороженного базиса 01–10 и согласований объёма. Изменения вносятся только через PR с ревью ведущего; каждая запись фиксирует влияние на FR, бэклог и стоимость.

## Правило изменения

1. Предложение изменения (автор, причина) → PR.
2. Оценка влияния: FR (коллега), бэклог/стоимость (ведущий).
3. Ревью и одобрение ведущего; при влиянии на объём — согласование с заказчиком.
4. Запись в журнал; при необходимости — версионирование артефакта.
