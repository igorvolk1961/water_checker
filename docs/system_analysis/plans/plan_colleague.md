# AquaPredict LIMS — План коллеги (Colleague Plan)

**Роль:** второй участник пары. **Зона:** функциональные требования, требования к пользовательскому интерфейсу, диаграммы (в т.ч. понятная бизнесу BPMN). **Общий вход:** замороженный базис `01…10`. Парный документ: `plans/plan_lead.md`.

## 1. Цели и результат

К концу работы — согласованный комплект: функциональные требования (`requirements/functional_requirements.md`), требования к UI (`requirements/ui_requirements.md`), диаграммы (`diagrams/`), согласованные с бэклогом и стоимостью ведущего.

## 4. Контрольные точки (для коллеги)

- **Gate 1:** выдан FR-скелет и карта экранов → ведущий разблокирован.
- **Gate 2:** детальные FR + UI готовы; юр-требования учтены; BPMN согласован с UC.
- **Gate 3:** FR/UI/BPMN заморожены (основа финальной стоимости).
- **Gate 4:** правки по ревью внесены, комплект целостен.

## 5. Definition of Done (артефакты коллеги)

- Термины строго из `02_glossary.md`; ID `FR-xx` и ссылки на UC; указана версия.
- Для UI — экраны и состояния; для BPMN — соответствие шагам UC.
- Изменения базиса (01–10) — только через PR с ревью ведущего.

## 6. Что НЕ входит в зону коллеги

Оценка стоимости, юридические требования, бэклог, трассируемость — зона ведущего (`plans/plan_lead.md`).
