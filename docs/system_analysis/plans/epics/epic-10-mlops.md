# EPIC-10 — MLOps: разметка, переобучение, дрейф

- **Релиз:** R2 · **Оценка:** 250 ч / 550 000 ₽
- **Источники:** US-10.1 · FR-11 · SCR-06/07 · BPMN uc6 · C4-3 (`TRAIN`, `EVAL`, `DRIFT`, `REG`) · LGL-13
- **Цель:** замкнуть цикл «данные → разметка → обучение → развёртывание» и следить за дрейфом.

## Задачи

- T-10.1 Агрегация обучающих примеров (Feature Vector + метка).
- T-10.2 Приоритет источника разметки (протокол > вердикт).
- T-10.3 Карантин «Конфликт разметки» до разрешения DS (FR-11.2).
- T-10.4 Пайплайн переобучения: метрики новой версии, «Утвердить и развернуть»/откат (MLflow).
- T-10.5 Непрерывный мониторинг дрейфа (входы: KS/PSI; ошибки: CUSUM/ADWIN), уведомления DS/ГТ.
- T-10.6 **API-компонент MLOps:** `/mlops/examples`, `/mlops/retraining`, `/mlops/drift`, `/models`.
- T-10.7 Тесты воспроизводимости переобучения/отката.

## Зависимости

- EPIC-09. Опирается EPIC-11.

## Definition of Done

- Конфликты в карантине; переобучение/откат воспроизводимы; дрейф отслеживается и виден в UI.

## Риски

- Дрейф без своевременного переобучения (PRJ-04).
