# Sequence v1 — UC5 (вариант A): протокол, сопроводительные данные и статус ФГИС-выгрузки

**Версия:** 0.1 (C-05). Показывает границу варианта A: валидация, ЭП и выгрузка — в контуре 1С; AquaPredict передаёт сопроводительные данные и читает статусы. Термины — `02_glossary.md`; процесс — BPMN UC5 (вариант A).

```mermaid
sequenceDiagram
    autonumber
    participant ЛБ as Лаборант / РЛ (в 1С)
    participant 1С as БИТ.Лаборатория (1С)
    participant AP as AquaPredict
    participant ФГИС as ФГИС Росаккредитации

    ЛБ->>1С: результаты анализов, формирование протокола
    1С->>1С: сверка с нормативами, валидация
    1С-->>AP: пробы, результаты LAB-01…16, статусы (OData, FR-08.1)
    AP->>AP: информационная сверка со справочником нормативов (подсветка на SCR-04, решение — в 1С, LGL-11)

    alt по партии есть предиктивные инциденты
        AP->>1С: HTTP-сервис: сопроводительные данные инцидента (срез телеметрии, КА) — состав по открытому вопросу 2 (FR-09.2)
    end

    ЛБ->>1С: валидация протокола РЛ
    ЛБ->>1С: ЭП ответственного (вид ЭП/подписант — открытый вопрос 1, контур 1С — LGL-02)
    1С->>ФГИС: экспорт XML через защищённый API-шлюз (LGL-01, выгрузка — контур 1С)
    ФГИС-->>1С: UUID зарегистрированной записи
    1С-->>AP: статус выгрузки + UUID (OData, FR-09.3)
    AP-->>ЛБ: отображение статуса на SCR-05 (read-only, LGL-07: неподписанные протоколы не показываются как «отправляемые»)

    Note over AP,ФГИС: AquaPredict не формирует XML, не подписывает и не отправляет, повторная отправка при отказе — контур 1С (FR-09.1/09.4)

    AP->>AP: ground truth → связка со срезом телеметрии → метка в обучающую выборку (UC6)
```
