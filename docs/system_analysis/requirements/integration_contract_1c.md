# Интеграция с «БИТ.Лаборатория» (1С) — контракт обмена

Назначение: зафиксировать перечень операций чтения и записи между AquaPredict и «БИТ.Лаборатория» (1С) — во исполнение FR-15. **Версия контракта: v1.0 — FROZEN** (зафиксирована 2026-10-13; изменения — новая версия, LGL-R3). Сторона 1С — администратор 1С заказчика (FR-15.4). Технологии — утверждённый стек (`architecture_stack.md`): чтение — OData, запись — HTTP-сервис, клиент `httpx`. Общие конвенции API — `api_contract.md`; события очереди — `domain_events.md`.

## 1. Чтение (OData)

| Сущность 1С | Что читаем | Назначение | FR |
| --- | --- | --- | --- |
| Партии | номер, даты начала/окончания, статус качества | привязка телеметрии (UC1) | FR-01, FR-15.1 |
| Пробы | идентификатор, партия, время отбора, штрихкод | связка «срез телеметрии → проба» | FR-08.4 |
| Результаты испытаний (LAB-01…16) | значения, единицы, метод | эталонная разметка (ground truth) | FR-08.1 |
| Протоколы / статусы | валидация, подпись (ПЭП РЛ), статус ФГИС, UUID | отображение read-only (SCR-04/05) | FR-09.3 |
| Планы отбора | плановые точки | контекст | FR-15.1 |

## 2. Запись (HTTP-сервис)

| Операция | Параметры | Ключ идемпотентности | FR |

| Установить/снять блокировку закрытия партии и комментарий | партия, статус/текст | партия + тип записи + версия | FR-01.4 |

## 3. Ограничения и правила

- Нагрузка на 1С — **не более 60 запросов/мин** (NFR-6): пакетирование, очередь, повторные попытки с экспоненциальной задержкой (FR-15.3).
- Все операции записи — с **ключом идемпотентности** (FR-15.6): ретрай не создаёт дубль задачи.
- Исходящие записи при недоступности 1С — в **персистентную очередь (Redis, AOF/RDB)** (FR-15.5).
- Каналы — защищённые: HTTPS/TLS (NFR-9).
- **Версионирование контракта**: при изменении состава операций/полей — новая версия, согласование (LGL-R3).

## 4. Доменные события (для очереди и аудита)

`RiskAlert`, `IncidentCreated`, `CorrectiveActionRequested`, `VerdictRecorded`, `BatchCloseBlocked`/`BatchCloseUnblocked`, `SamplingRequested`.
