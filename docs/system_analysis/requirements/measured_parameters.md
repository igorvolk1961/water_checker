# AquaPredict LIMS — Измеряемые параметры (Measured Parameters)

Канонический перечень измеряемых параметров системы. Единый источник для: KPI-спецификации (L-02), функциональных требований и UI коллеги (I-3, I-5, I-10), доменной модели (`06_domain_model.md`), требований к данным (`08_data_requirements.md`). Конкретные адреса OPC-UA, единицы и частоты — предварительные и уточняются на объекте (см. §6).

## 4. Привязка к нормативам

- **СанПиН 1.2.3685-21** — ПДК химических и микробиологических показателей (LAB-01…LAB-16).
- **ГОСТ 32220-2013** — правила приёмки, методы контроля, требования по категориям воды.
- Категория воды (первая / высшая) влияет на строгость нормативов.

## 5. Связь с другими артефактами

- `06_domain_model.md` — `ПоказаниеДатчика` (`sensor_id`, `value`, `unit`) раскрывается через TEL-01…TEL-13; `целевой_параметр` — через LAB-01/05/09.
- `05_use_case_specification.md` — событие `RiskAlert.параметр_риска` ссылается на целевой показатель из §3.
- `08_data_requirements.md`, `10_cold_start_and_archival_data.md` — источники и матчинг (OPC-UA/HDA, журналы).
- `kpi.md` (L-02) — метрики по слоям задаются по каждому целевому показателю §3.

## 6. Допущения

- Tag-идентификаторы и адреса OPC-UA, единицы и частоты — предварительные, уточняются на объекте.
- Перечень параметров принят по базису 01–10; расширяется по результатам обследования линии.
- Опциональные параметры (TEL-11, TEL-13) присутствуют не на каждой линии.
