# Интеграция с «БИТ:LIMS» (1С) — контракт обмена

Назначение: зафиксировать перечень операций чтения и записи между AquaPredict и «БИТ:LIMS» (1С) — во исполнение FR-15. **Версия контракта: v1.0 — FROZEN** (зафиксирована 2026-10-13; изменения — новая версия, LGL-R3). Сторона 1С — администратор 1С заказчика (FR-15.4). Технологии — утверждённый стек (`architecture_stack.md`): чтение — OData, запись — HTTP-сервис, клиент `httpx`. Общие конвенции API — `api_contract.md`; события очереди — `domain_events.md`.

## 1. Чтение (OData)

| Сущность 1С | Что читаем | Назначение | FR |
| --- | --- | --- | --- |
| Партии | номер, даты начала/окончания, статус качества | привязка телеметрии (UC1) | FR-01, FR-15.1 |

| Планы отбора | плановые точки | контекст | FR-15.1 |

## 3. Ограничения и правила

- Нагрузка на 1С — **не более 60 запросов/мин** (NFR-6): пакетирование, очередь, повторные попытки с экспоненциальной задержкой (FR-15.3).
- Все операции записи — с **ключом идемпотентности** (FR-15.6): ретрай не создаёт дубль задачи.
- Исходящие записи при недоступности 1С — в **персистентную очередь (Redis, AOF/RDB)** (FR-15.5).
- Каналы — защищённые: HTTPS/TLS (NFR-9).
- **Версионирование контракта**: при изменении состава операций/полей — новая версия, согласование (LGL-R3).

## 4. Доменные события (для очереди и аудита)

`RiskAlert`, `IncidentCreated`, `CorrectiveActionRequested`, `VerdictRecorded`, `BatchCloseBlocked`/`BatchCloseUnblocked`, `SamplingRequested`.

## 5. Открытые вопросы

- Точные имена OData-сущностей и HTTP-методов на стороне 1С определяются администратором 1С (В-7.3, FR-15.4).

## 6. Основание, доступ к реальному API и «мост»

- Настоящий контракт — **проектный (design-time) документ**. Составлен на основе требований FR-15 и домена AquaPredict, а также **стандартных возможностей платформы «1С:Предприятие 8»** (автоматический REST-интерфейс **OData** для чтения; **HTTP-сервисы** для записи).
- **Вендорское имя продукта — «БИТ:LIMS»** (разработчик — ООО «Первый Бит»). В проекте ранее использовалось название «БИТ.Лаборатория»; оно приведено к вендорскому.
- **Доступ к реальному API заказчика.** На момент проектирования доступ к метаданным/API конфигурации заказчика **не предоставлен**. Публичной технической документации по API и схеме данных «БИТ:LIMS» **нет** (в открытом доступе — только маркетинговые материалы и руководство пользователя; описаний OData-сущностей и HTTP-методов не публикуется).
- **Следствие.** Имена сущностей/методов/полей/статусов в разделах 1–2 — **условные**; они подлежат уточнению администратором 1С заказчика (В-7.3, FR-15.4). Контракт фиксирует **нашу сторону** (состав операций и конвенции), а не фактическую реализацию в 1С.
- **Мост (integration bridge / adapter).** При появлении доступа к реальному API (и тестовому контуру 1С) реализуется **слой-мост** между AquaPredict и «БИТ:LIMS»: подключение к фактическому OData/HTTP-интерфейсу, **маппинг** реальных сущностей/методов/статусов на внутренние модели, обработка лимитов и ошибок. Мост изолирует прикладную часть от особенностей конфигурации (паттерн Adapter/ACL, `architecture.md` §4). Его объём и сроки оцениваются **после получения доступа**, отдельной задачей EPIC-01.
