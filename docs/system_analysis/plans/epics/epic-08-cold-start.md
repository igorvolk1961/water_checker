# EPIC-08 — Cold Start: ETL архива, Baseline, Shadow

- **Релиз:** R1 · **Оценка:** 320 ч / 700 000 ₽
- **Источники:** US-08.1 · FR-10 · SCR-08 · BPMN uc7 · C4-3 (`TRAIN`, `QUAL`) · `10_cold_start_and_archival_data.md`
- **Цель:** запустить систему до накопления меток — за счёт архива и профиля нормы.

## Задачи

- T-08.1 ETL-импорт архива (SCADA Historian CSV / OPC-UA HDA, журналы) + отчёт о качестве.
- T-08.2 Матчинг «срез 2 ч → проба» + отчёт (цель ≥ 90 %); повторный запуск на подмножестве.
- T-08.3 Обучение Baseline-профиля (Anomaly Detection, Unsupervised), статус [Черновик]→[Эталонный] (подтверждает ГТ).
- T-08.4 Shadow Mode после подтверждения профиля.
- T-08.5 Pre-training на синтетике (поток 7а) при дефиците данных.
- T-08.6 **API-компонент холодного старта:** `/coldstart/import`, `/coldstart/match`, `/coldstart/baseline`.
- T-08.7 **Тестовый датасет** (маскированный архив + синтетика) для прогонов без данных заказчика.
- T-08.8 Отчёты о качестве импорта/матчинга.

## Зависимости

- EPIC-02, EPIC-07. Опирается EPIC-09.

## Definition of Done

- Импорт и матчинг с отчётами; Baseline подтверждён как «Эталонный»; режим Shadow активен.

## Риски

- Качество/дефицит архива (PRJ-02/03).
