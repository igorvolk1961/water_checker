# AquaPredict LIMS — План ведущего (Lead Plan)

**Роль:** ведущий пары. **Зона:** оценка стоимости, юридические риски и требования, продуктовый бэклог, матрица трассируемости, интеграция и целостность артефактов. **Общий вход:** замороженный базис `01…10`. Парный документ: `plans/plan_colleague.md`.

## 1. Цели и результат

К концу работы — согласованный комплект: юридические требования (`legal/`), оценка стоимости (`cost/`), продуктовый бэклог (`backlog/`), матрица трассируемости (`traceability.md`), стыкованные с FR/UI/BPMN коллеги.

## 4. Контрольные точки (мои)

- **Gate 0:** базис заморожен, правила (ветки/PR, DoD, метод оценки) приняты.
- **Gate 1:** получен FR-скелет → можно строить/уточнять бэклог и оценку.
- **Gate 2:** юр-требования учтены в FR/UI; BPMN согласован с UC.
- **Gate 3:** FR/UI/BPMN заморожены → финальная стоимость и Stories.
- **Gate 4:** целостный комплект, трассируемость полная.

## 5. Definition of Done (мои артефакты)

- Термины строго из `02_glossary.md`; есть ID и ссылки на UC/FR/LGL; указана версия.
- Для бэклога — критерии приёмки; для стоимости — метод и допущения.
- Изменения базиса — только через PR с ревью.

## 6. Что НЕ входит в мою зону

Функциональные требования, требования к UI, BPMN/Sequence/State — зона коллеги (`plans/plan_colleague.md`).
