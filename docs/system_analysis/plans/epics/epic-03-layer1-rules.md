# EPIC-03 — Движок риск-скоринга, Слой 1 (rule-based)

- **Релиз:** R1 · **Оценка:** 180 ч / 400 000 ₽
- **Источники:** US-03.1 · FR-03 · BPMN uc2 · C4-3 (`ENGINE`) · `kpi.md` §2
- **Цель:** оценивать риск по настраиваемым правилам телеметрии (старт без размеченных данных).

## Задачи

- T-03.1 Справочник правил (условие, TEL-код, порог, действие) + CRUD администратора с аудитом (LGL-03).
- T-03.2 Расчёт риска по правилам; признак источника «Слой 1».
- T-03.3 **API-компонент движка:** `/rules` (CRUD), `/score` (расчёт по срезу).
- T-03.4 Старт без меток: акцент Precision/FPR (Recall не нормируется).
- T-03.5 Стартовая комплектация правил (гипотеза: температура/озон/мутность → ОМЧ) — с ML-инженером.
- T-03.6 Юнит-тесты правил и граничных условий.

## Зависимости

- EPIC-02. Опирается EPIC-04.

## Definition of Done

- Правила настраиваются и применяются; риск-скор формируется с источником «Слой 1»; аудит изменений правил ведётся.

## Риски

- Подбор стартовой комплектации правил (гипотеза, уточняется на данных).
