# EPIC-07 — Чтение лабораторных результатов (Ground Truth)

- **Релиз:** R1 · **Оценка:** 140 ч / 300 000 ₽
- **Источники:** US-07.1 · FR-08, FR-09 · SCR-04/05 · BPMN uc5 · C4-3 (`LABEL`, `SYNC`) · LGL-01/02/07/11
- **Цель:** получать утверждённые результаты как целевую переменную (read-only), не дублируя лабораторный контур.

## Задачи

- T-07.1 Чтение утверждённых результатов и статусов (OData).
- T-07.2 Информационная сверка с нормативами (СанПиН/ГОСТ); решение о несоответствии — в 1С (LGL-11).
- T-07.3 Чтение статуса ФГИС/UUID (read-only).
- T-07.4 Запрет собственного журнала проб и подписания (LGL-07).
- T-07.5 **API-компонент результатов:** `/lab-results`, `/lab-results/{id}/status`.
- T-07.6 Тесты маппинга результатов на целевую переменную (на моке 1С).

## Зависимости

- EPIC-01. Опираются EPIC-08, EPIC-10.

## Definition of Done

- Результаты читаются как метка; сверка информационная; собственный журнал проб отсутствует.

## Риски

- Задержка появления утверждённых результатов (влияет на обучение).
