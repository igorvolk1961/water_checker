# Приложение № 4 к Договору — Права на результаты и лицензии

> Проект документа для учебного проекта. Редакция 1.0, 2026-10-13. Не является юридическим заключением.

## 1. Исключительные права

1.1. Исключительные права на созданное по договору программное обеспечение (Систему AquaPredict), исходный код, документацию и обученные модели переходят Заказчику с момента полной оплаты работ (п. 5.1 Договора).
1.2. До перехода прав Исполнитель предоставляет Заказчику неисключительную лицензию на использование промежуточных результатов в целях приёмки.
1.3. Права на данные Заказчика (телеметрия, лабораторные данные, логи) остаются у Заказчика (п. 5.3 Договора). Обучающие датасеты, сформированные из данных Заказчика, передаются Заказчику вместе с моделью.

## 2. Лицензии сторонних компонентов

| Компонент | Назначение | Лицензия | Примечание |
| --- | --- | --- | --- |
| scikit-learn | ML-модели (Слой 2) | BSD-3 | свободная |
| MLflow | MLOps, реестр моделей | Apache-2.0 | свободная |
| FastAPI / Pydantic | API-слой | MIT | свободная |
| httpx / asyncua / paho-mqtt | интеграции (1С, OPC-UA, MQTT) | BSD / MIT / EPL-2.0 | свободные |
| PostgreSQL / Redis | СУБД / очередь | PostgreSQL License / RSALv2-SSPLv1 | свободные |
| «1С:БИТ.Лаборатория» | учётная система Заказчика | коммерческая | лицензия у Заказчика; Исполнитель не воспроизводит и не передаёт её |

2.1. Исполнитель раскрывает полный перечень зависимостей (lock-файл) при передаче результатов и обязуется уведомить о лицензионных изменениях.
2.2. Сторонние компоненты с копилефт-лицензиями, влияющими на исключительные права Заказчика, не используются без предварительного письменного согласия Заказчика.

## 3. Гарантии чистоты прав

3.1. Исполнитель гарантирует, что результаты созданы силами Исполнителя, не нарушают прав третьих лиц и не содержат компонентов, использование которых несовместимо с передачей исключительных прав Заказчику.
3.2. При предъявлении третьих лиц претензий по правам на результаты Исполнитель участвует в защите за свой счёт (возмещение убытков в пределах, установленных п. 6.5 Договора).
